# オペレーションウィンドウ

Static Instances ウィンドウでは、シーンのベイク、既存の LODGroup コンテンツの変換、
メッシュ LOD の生成、風を取り除いた SpeedTree マテリアルの生成を行います。コンポーネントの
設定は [SIS Inspector](StaticInstanceScatterInspector.ja.md) で、プロジェクトのポリシーは
[Graphics Settings](GraphicsSettings.ja.md) で扱います。

## ウィンドウを開く

**Window > Rendering > Static Instances** を選びます。または **Edit >
Project Settings > Graphics > Static Instances** を開き、**Open Operations
Window** を選択します。ウィンドウのタイトルは **Static Instances** です。

シーン操作は Edit モードで開始してください。主要なアクションは、Play 中、Play への
遷移中、シーンのバッチ処理の実行中は無効になります。有効なアクティブシーンが必要です。
対象が空の場合は通常、何もすることがない旨が報告されますが、ボタンが無効になるとは
限りません。操作の結果と検証メッセージは Console で、バッチの進捗はウィンドウの
ステータス領域で確認してください。

## Scene Operations

**アクティブシーン**とは、Hierarchy でアクティブとして選択されているシーンです。
**ロード中のシーン**には、加算ロードされたシーンも含まれます。各ボタンの対象範囲は
意図的に異なります。オブジェクトを選択しても対象範囲は絞り込まれません。

| 設定 | 用途 |
| --- | --- |
| **Bake Loaded Sources** | ロード中のすべてのシーンの SIS ソースをベイクします。このアクションが保存するのはアクティブシーンのみです。変更されたその他のシーンは個別に保存してください。 |
| **Validate** | ロード中のシーンにわたる対象について、変更を加えずにベイク/ソースの問題を報告します。ベイク前に、ブロッキングとなるソースのエラーを解消してください。 |
| **Clear Baked Data** | 確認の後、アクティブシーンの SIS のベイクを削除してシーンを保存します。その他のロード中のシーンには触れません。その後、他から参照されなくなった、風を取り除いたマテリアルのクローンを回収します。 |
| **Convert FOV** | LODGroup のスクリーン高さをメートル距離に一度だけ変換する際に使う垂直視野角です。範囲は 10–120 度です。初期値は Camera.main の FOV、存在しない場合は 60 度です。基準解像度は不要です。この入力値は保存されず、変換後に追跡されることもありません。 |
| **Convert LOD Groups…** | アクティブシーンの LODGroup のプレビューを開きます。変換を適用すると LOD0 が残り、より粗いレンダラーと LODGroup は削除されます。適用前に階層の変更内容を確認してください。 |
| **Generate Mesh LODs…** | ロード中のシーンにわたる SIS コンポーネント配下のメッシュについて、プレビューを開きます。サポートされるインポーターの生成機能を有効にするか、メッシュのコピーアセットを作成して MeshFilter の参照を付け替えます。これは LODGroup の変換後に行う別の手順です。 |

**Clear Baked Data** はコンポーネントの Undo を記録しますが、削除されたマテリアルアセットは
Undo では復元できません。参照されているクローンは保持されます。シーンの保存に失敗した場合、
クリアはメモリ上に残り、マテリアルの回収は実行されません。

### Convert LOD Groups のプレビュー

プレビューでは、階層を変更する前に、シーンの範囲、予定されている変更、変換後のメートル距離、
警告を表示します。変換には現在の Unity の `QualitySettings.lodBias` が反映されます。
変換後の距離は、その値の以降の変更には追従しません。変換によって Screen Size の割合の
ラダーがオーサリングされることはありません。

| 設定 | 用途 |
| --- | --- |
| **Restore "LOD1+ do not cast" as Shadow Cast Max Level** | 条件を満たす各 SIS オーナーについて、そのオーナーのグループからシャドウレベルのカットオフを任意で導出します。部分的な多数決に関する警告を確認してください。カットオフは条件を満たさないグループにも影響します。保存されたカットオフは、有効な LOD ラダーがなければ効果がありません。 |
| スキップされたグループのチェックボックス | 動的な要素が検出されたグループでも、個別に変換対象に含めます。実際にアニメーション・移動・シミュレーションするコンテンツは SIS の対象外にしてください。オーナー配下にスキップされた LODGroup があると、そのオーナーのベイクは引き続き妨げられます。 |
| **Only objects with custom components** | 削除リストを絞り込みます。オフにすると、他のオブジェクトのスクリプトから駆動されるものを含め、削除予定のすべての GameObject を確認できます。 |
| 検索 | 削除リストをオブジェクト名で絞り込みます。絞り込みで非表示になったオブジェクトが保護されるわけではありません。 |
| 削除リストのチェックボックス | 選択した GameObject を削除から保護します。粗いレンダラーは削除されます。自動検出で識別できない、必要なゲームプレイ用オブジェクトに使います。 |
| グループ行または削除行の **Select** | 確認のためにその GameObject を選択して強調表示します。変換計画は変更しません。 |
| **Cancel** | 変換を適用せずにプレビューを閉じます。 |
| **Convert** | 確認した計画を適用し、シーンを未保存状態にします。変換されるグループがない場合は無効です。適用後に保存してください。 |

シーンの変換では通常 Undo が記録されます。影響するレンダラーが 2,000 を超える場合は、
記録のコストが高くなることがあるため、Undo ありまたはなしで変換するかを選択できます。
どちらを選んでも、別段階であるインポーターや生成アセットの変更は元に戻りません。

### Generate Mesh LODs のプレビュー

プレビューには、ロード中のシーンの範囲と、インポーターの変更、生成されるコピー、参照の
更新、既存のチェーン、以前に処理された単一レベルのメッシュ、アセットパスのないメッシュの
件数が表示されます。生成後も単一レベルのままのメッシュは、単に削減するには三角形が
少なすぎる可能性があります。その場合も唯一のレベルで描画されます。

| 設定 | 用途 |
| --- | --- |
| **Copy asset folder** | 生成するメッシュコピーの出力先で、必要に応じて作成されます。フォルダーを変更すると計画が再解析されます。別のフォルダーにあるコピーはこの検索では見つからず、再度生成されることがあります。 |
| **Also list the meshes nothing happens to** | 変更されないメッシュもプレビューに含めます。オフの場合、リストには今回の実行での変更が表示されます。 |
| メッシュリスト | 一覧の各メッシュについて、予定されているアクションとソースを表示します。生成前に確認してください。 |
| メッシュ行の **Select** | 確認のためにソースのメッシュアセットを選択して強調表示します。 |
| **Cancel** | 生成せずにプレビューを閉じます。 |
| **Generate** | 計画を適用します。作業がない場合は無効です。MeshFilter の参照が付け替えられたシーンを保存してください。 |

インポーターの変更と生成されたメッシュアセットは Undo できません。適用前にバージョン管理
またはアセットのバックアップを使用してください。MeshFilter の参照の変更は通常 Undo が
記録されます。付け替えが 2,000 を超える場合、ダイアログでその記録の有無を選んで生成
できます。この選択によってアセットの変更が Undo 可能になるわけではありません。生成された
メッシュチェーンを確認し、SIS Inspector で目的の LOD 設定をオーサリングしてください。

## Selected Scenes

このセクションでは、複数のプロジェクトシーンを順にベイク・保存します。
リストはアセットパス順に並びます。パッケージ内のシーンは読み取り専用のエントリとして
表示され、選択できるのは **Assets/** 以下のシーンパスのみです。

| 設定 | 用途 |
| --- | --- |
| **Select All** | Assets 以下の一覧にあるプロジェクトシーンをすべてチェックします。 |
| **Select None** | 選択を解除します。 |
| **Refresh** | シーンリストを更新します。削除されたパスは選択から外れます。プロジェクトに変更があった場合もリストは更新されます。 |
| シーンのチェックボックス | 処理する保存済みシーンを選択します。パッケージの行はチェックできません。 |
| **Bake Selected Scenes** | 選択した各シーンを検証・ベイクし、風を取り除いた SpeedTree マテリアルを生成し、そのシーンの保存を確認してから次へ進みます。Play モードには入りません。少なくとも 1 つのシーンの選択が必要です。 |
| **Cancel After Current Operation** | 実行中のバッチのキャンセルを要求します。それまでに完了した保存は保存されたままです。 |
| ステータス領域 | 進捗、完了、キャンセル、エラー (保存やシーン復元の失敗を含む) を報告します。 |

走査を開始する前に、確認が表示されたら開いているシーンを保存してください。Cancel を
選ぶと開始を中止します。**Don't Save** を選んでも編集内容の破棄が許可されるわけでは
ありません。未保存のシーンや保存パスのないシーンが残っていると、走査は行われません。
選択した各シーンは、そのオーナーを変更する前に検証されます。再ベイクで修復できる古い
ベイクデータや移動したベイクデータは、それ自体では再ベイクを妨げません。ブロッキングと
なるソースのエラーは妨げます。

バッチが正常に完了すると、元のロード済みシーンの構成が復元されます。操作によって未保存の
変更が残った場合 (保存に失敗した後を含む)、ツールは以前の構成を復元するために編集内容を
破棄するのではなく、そのシーンを開いたままにします。

バッチによる保存、シーンの走査、アセットの作成/削除は、1 つのアトミックな Undo
トランザクションにはなりません。個々のベイクやレコードの更新はコンポーネントの Undo を
記録しますが、完了した複数シーンのバッチを Undo で巻き戻すことは想定しないでください。
そのためには、保存済みのベースラインやバージョン管理のチェックポイントを用意してください。

## 生成されるアセット

SIS は SpeedTree の風をシミュレーションしません。マテリアルが SpeedTree の風キーワード
(`_WIND_SHARED`、`_WIND_BRANCH1`、`_WIND_BRANCH2`、`_WIND_RIPPLE`、`_WIND_SHIMMER`) を
有効にしているベイク済みのすべての描画グループに対し、**Bake Loaded Sources** と
**Bake Selected Scenes** は風を取り除いたクローンマテリアルを生成し、SIS はそのクローンを
描画します。これにより SpeedTree の木は風の頂点処理コストなしで静止状態で描画されます。
ビルド時の自動ベイクは、既存の最新のクローンを再接続しますが、新しいクローンは作成できません。
クローンが生成されていないグループは元のマテリアルを使い続け、静止状態で描画されますが、
風の頂点処理コストは引き続きかかります。

| アセットまたは状態 | 扱い |
| --- | --- |
| 風を取り除いたマテリアル | `Assets/SIS_WindStatic` 以下に永続的に生成されるアセットです。SIS は元の SpeedTree マテリアルの代わりにこれを描画します。Clear は、シーンの保存に成功した後、回収対象となる参照されていないクローンのみを回収します。 |
| メッシュ LOD のコピー | プレビューの Copy asset folder に置かれる永続的なアセットです。風を取り除いたマテリアルとは別物で、シーンの参照変更を Undo しても削除されません。 |
