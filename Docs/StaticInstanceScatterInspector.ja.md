# Static Instance Scatter Inspector

Static Instance Scatter (SIS) は、コンポーネント配下の静的な MeshRenderer のコンテンツを
インスタンスとして描画します。その Inspector で、インスタンス単位の可視性、メッシュ LOD の
選択、遷移フェードを設定します。ベイクとシーン操作は
[オペレーションウィンドウ](OperationsWindow.ja.md)に、プロジェクトの既定値は
[Graphics Settings](GraphicsSettings.ja.md) にあります。

インストール、サポートされるコンテンツ、最初のシーンについては、
[ユーザーガイド](UserGuide.ja.md)から始めてください。このページでは、コンポーネントの
Inspector を通常の表示順に説明します。以下の既定値は新しく追加したコンポーネントのものです。
保存済みのシーンやプリセットは、オーサリングした値を保持します。

## Inspector を開く

1. 静的なソースレンダラーを含む親 GameObject を選択します。
2. **Add Component > Rendering > Static Instance Scatter** を選びます。
3. その GameObject を選択すると、Inspector でコンポーネントを編集できます。

ソースオブジェクトはコンポーネントの配下に置き、SIS コンポーネントを入れ子にしないで
ください。インスタンスの Transform、メッシュ、マテリアルは初期化後は静的です。ソースの
ジオメトリを変更したら再ベイクと再初期化を行ってください。ソースの Transform を移動しても、
初期化済みのインスタンスバッファーは更新されません。

Inspector は複数オブジェクトの編集をサポートします。値が混在している場合は混在として
表示されます。コンポーネントごとのバウンズとランタイムのカウントは、単一選択の場合のみ
表示されます。折りたたみ状態は Editor のセッション中は記憶されます。**LOD** は初期状態で
開いており、**Debug (Development)** は初期状態で閉じています。

## ステータスとセットアップのメッセージ

Inspector の上部には、読み取り専用のベイクステータスと、該当するセットアップの
メッセージが表示されます。複数のメッセージが同時に表示されることがあります。

| 表示またはアクション | 用途 |
| --- | --- |
| BatchRendererGroup Variants の警告 | **Project Settings > Graphics > Shader Stripping > BatchRendererGroup Variants** が **Keep All** でない場合に表示されます。**Open Project Settings > Graphics ...** でそのページを開けます。 |
| ベイクステータス | 未ベイクのコンテンツ、ベイク済みインスタンス数とキャッシュの鮮度、またはブロッキングとなる検証エラーを報告します。複数選択時は選択範囲の検証ステータスを報告し、選択が大きい場合は部分スキャンである旨の通知が出ます。 |
| 入れ子コンポーネントの警告 | サポートされない SIS の入れ子を報告します。**Select the nested component** で、修正のために内側のコンポーネントを選択します。 |
| ベイク済みプレハブの警告 | プレハブアセットまたは Prefab Mode に保存されたワールド空間のベイクデータを報告します。**Clear baked data** で、該当するプレハブのコンポーネントからそれらの配列を削除します。代わりに、配置されたシーン上のインスタンスをベイクしてください。 |
| LODGroup 変換の警告 | SIS が既存の LODGroup のコンテンツを使うには変換が必要です。**Convert LOD Groups in this hierarchy…**、選択した階層向けのバリエーション、または **Review skipped LOD Groups…** で、選択範囲を対象とした変換プレビューを開きます。 |

自動再ベイクは Graphics Settings の **Bake On Entering Play Mode** と **Bake On Build** に
依存します。ステータスメッセージは、これらのポリシーの確認の代わりにはなりません。詳細な
エラーはオペレーションウィンドウで **Validate** を実行して確認してください。
変換とメッシュ LOD の生成は別々の操作です。変換プレビューを適用する前に
[オペレーションウィンドウ](OperationsWindow.ja.md)を参照してください。

## Draw Range と共通のフェード設定

これらの行は、**LOD > Enabled** がオフの場合や、レベル範囲に 1 レベルしか含まれない場合も
表示されます。メッシュ LOD の遷移だけでなく、Draw Range も制御します。

| 設定 | 用途 | 既定値と単位 |
| --- | --- | --- |
| **Draw Range > Min** | 描画を許可する最も近い距離です。`0` でオーサリングによる近方の制限を無効にします。 | `0` メートル。非負。 |
| **Draw Range > Max** | 描画を許可する最も遠い距離です。`0` でオーサリングによる遠方の制限を無効にします。サイズから導出された別のカットオフは引き続き適用されることがあります。 | `0` メートル。非負。 |
| **Fade Mode** | 遷移を駆動するものを **None**、**Distance**、**Time** から選びます。**Transition Metric** とは独立しています。 | **Time**。 |
| **Fade Width** | メッシュ LOD の境界の手前、およびオーサリングした Draw Range の制限の内側における Distance フェードの帯の幅です。`0` で即時に切り替わる境界になります。 | `5` メートル。非負。クロスフェードのサポートが有効な場合に、Distance フェードで編集できます。 |
| **Fade Duration** | Time 遷移の長さです。`0` の場合はプロジェクトの duration に従います。フェードしない場合は None を使います。 | `0`。Inspector のスライダーは `0–1` 秒。プロジェクトの duration の初期値は `0.5` 秒です。 |
| **Hysteresis** | 境界を戻る方向に越えるために必要な追加の距離で、カメラの揺れによる切り替えの繰り返しを抑えます。メッシュ LOD と該当する Draw Range の境界に適用されます。 | `5` メートル。非負。実効的な Distance モードで Fade Width が正の値の間は無効です。 |

Fade Width と Fade Duration は、適用されない場合も表示されたまま無効になります。
Fade Mode が混在した選択では、プロジェクトのクロスフェードのサポートが許可していれば、
モードに依存する編集は引き続き可能です。モードを変更しても、オーサリングしたその他の値は
保持されます。

### フェードの挙動を選ぶ

| Fade Mode | 挙動 |
| --- | --- |
| **None** | 該当するヒステリシスを伴う即時の遷移です。サイズから導出された制限も即時にカットされます。 |
| **Distance** | 空間的な帯の中でカメラ位置に追従してブレンドします。帯の中で止まると現在のブレンドを維持し、方向を反転するとブレンドも逆に進みます。カメラカットは即座に解決されます。Screen Size による選択でも、Fade Width はメートルのままです。 |
| **Time** | 遷移がトリガーされると、カメラが止まっても Fade Duration をかけて進行します。ヒステリシスは遷移がトリガーされるタイミングを制御するもので、duration とは目的が異なります。シャドウは可視性のフェードに追従します。 |

実効的な Distance の Fade Width が正の値の場合、その境界の空間的な帯はそれによって
供給されるため、ヒステリシスが同じ遷移をさらに移動させることはありません。即時の境界と
Time 遷移のトリガーには、代わりに該当するヒステリシスが使われます。Draw Range に限り、
ランタイムは実効的なヒステリシスを、解決された近方と遠方の制限の間の距離の半分以下に
制限します。これは 2 つの再進入のしきい値が交差しないようにするためで、すべてのメッシュ
LOD 境界に半区間の制限を課すものではありません。

フェードには、SIS のプロジェクトのフェード設定 **Enabled** と、URP Asset の
**LOD Cross Fade** のサポートが必要です。開発用のグローバルなクロスフェードのマスクでも
無効にできます。サポートが無効な場合、オーサリングしたコンポーネントのモードは保持された
まま、実効的なフェードは None になります。マテリアルは URP/Lit と同様に
`LOD_FADE_CROSSFADE` をサポートする必要があります。メッシュ LOD を強制すると無効になるのは
メッシュ間のフェードのみで、Draw Range は共通の実効フェードモードを保持します。

### Draw Range の距離の解釈

**Draw Range は、メッシュ LOD が有効かどうかとは独立しています。** 保存されている
Transition Metric によって距離の解釈が決まります。

| 指標 | Draw Range の解釈 |
| --- | --- |
| **Distance** | 各インスタンスのバウンディングスフィアを使用します。オーサリングした遠方の制限にはその半径が加わり、近方の制限はその半径分だけ (0 まで) 縮められます。該当する FOV トラッキングと SIS の LOD Bias がこれらのしきい値をスケールします。 |
| **Screen Size** | オーサリングした Min と Max は、カメラからインスタンス中心までの絶対距離です。半径のオフセットはなく、FOV や SIS の LOD Bias によるスケールもされません。 |

Min を 0 以外の Max より大きく編集すると Max が外側に移動し、Max を Min より小さく編集すると
Min が内側に移動します。編集したフィールドが優先され、Inspector は有効な区間を保ちます。
Max の `0` は無制限を表す値のままです。

範囲外の可視性はシャドウも制御します。Time フェードでは、出力が停止する前にフェードアウトが
完了することがあります。Min は放射方向の距離であり、カメラのニアクリップ面ではありません。
透視投影での SIS のカリングは、カメラの視錐台のニア/ファー面の代わりに Draw Range を
使用します。距離の上限が必要な場合は、カメラのファークリップ距離を超えて広がるシーンも
含め、Max を明示的にオーサリングしてください。

### その他の遠方カリングの要因

| 要因 | Draw Range およびフェードとの相互作用 |
| --- | --- |
| Screen Size の **Culled (% Screen Size)** | このコンポーネントに、サイズに比例した遠方のカットオフを設定します。Draw Range Max は追加の絶対的な上限として残り、先に到達したカットオフが優先されます。 |
| Distance 指標とプロジェクトの **Size-Based Culling > Cull Distance Scale** | 各インスタンスのベイク済みのスフィアのサイズと形状補正から制限を導出します。プロジェクトのスケールが `0` の場合、この要因は無効です。オーサリングした Max がある場合は、結果として小さい方のしきい値が優先されます。 |

サイズから導出された制限が優先される場合、その Distance モードの帯にはプロジェクトの
**Derived Cull Fade Fraction** が使われます。これは Screen Size の Culled 比率が優先される
場合も同様です。Screen Size ではプロジェクトのサイズカリングのスケールが働かないことは、
このフェードの割合を無効にしません。オーサリングした制限が優先される場合は Fade Width を
使います。遠方の制限が等しい場合、Distance による選択ではオーサリングした幅を使います。
Screen Size による選択では、等しい場合は比率から導出された幅を保持し、絶対値の Max が
厳密に小さい場合にのみオーサリングした幅に切り替わります。Time は Fade Duration を使い、
None は即時にカットします。近方側はオーサリングしたフェード設定を使います。

プロジェクトのサイズカリングのスケールは、メッシュ LOD が無効であっても Screen Size の
コンポーネントには適用されません。保存されている Culled 比率と絶対値の Draw Range は
引き続き適用されます。指標と比率の編集コントロールは、有効な複数レベルの LOD セクション内に
あります。そのセクションを無効にしても、保存されている範囲の設定はリセットされません。
この Inspector でそれらを確認・変更するには、一時的に複数レベルの LOD 範囲を有効にし、
その後で意図した LOD Enabled の状態に戻してください。

## Motion Vector

このオプションは **Hysteresis** のすぐ下、Bounds の前にあり、既定値は**オフ**です。
マテリアルが対応する URP の MotionVectors パスを提供している場合に、独自の頂点アニメーション
(VAT など) のために初期化前に有効にします。これは初期化時の設定であり、変更には再初期化が
必要です。

VAT や独自の変形では、シェーダーが前フレームの変形後の頂点位置を正しく供給し、DOTS
インスタンシングをサポートする必要があります。このオプションを有効にするとパスが要求されますが、
アニメーションの履歴を構築したり、TAA やモーションブラーを有効にしたりはしません。通常の
変更不可のインスタンス Transform は引き続き必要です。
[シェーダーの要件](UserGuide.ja.md#頂点アニメーション用のモーションベクトル)を参照してください。

風を取り除いた SpeedTree のクローンを描画するグループは、オブジェクト単位の MV を発行しません。
そのオーナー内の他のグループでは、このオプションを引き続き使用できます。

## バウンズと広がりの計測値

これらの値はベイク済みのコンテンツを表す読み取り専用の値です。編集可能なカリングボックスを
提供するものではなく、インスタンス単位のバウンズを置き換えるものでもありません。

| 表示 | 用途 |
| --- | --- |
| **Bounds Center** | すべてのベイク済みインスタンスを含む和集合 AABB の、ワールド空間での中心です。 |
| **Bounds Size** | その和集合 AABB のワールド空間での寸法 (メートル) です。想定外に大きい寸法は、はぐれたインスタンスの存在を示している可能性があります。 |
| **Spread Diagonal** | 和集合 AABB の対角線の長さ (メートル) です。 |
| **Mean Instance Size** | インスタンスのバウンディングスフィアの直径の平均値 (メートル) と、この平均直径に対する広がりの対角線の比率です。 |

未ベイクのコンポーネントでは **Bounds: bake to display** と表示されます。複数選択時は、
代わりに選択したスキャッターの数が表示されます。広がりの 2 行は、単一のベイク済み
コンポーネントで、広がりの比率が正かつ `50x` 以下の場合にのみ表示されます。

## LOD

ソースメッシュに必要なメッシュ LOD レベルが揃ってから、メッシュ LOD を有効にします。
推奨する初期構成は、**Screen Size** と **Time** フェードの組み合わせです。
Transition Metric を変更しても、不足しているメッシュレベルは生成されません。

| 設定 | 用途 | 既定値と利用条件 |
| --- | --- | --- |
| **Enabled** | コンポーネントのメッシュ LOD 選択を有効にします。オフの場合はメッシュレベル 0 を描画し、Draw Range とそのフェードは有効なままです。 | オフ。 |
| **LOD Level Range** | ラダーで使用するメッシュレベルの Min/Max です。レベル 0 が最も詳細です。範囲をスライドするとレベルのラベルが変わり、オーサリングした境界値は保持されます。 | Min `0`、Max `1`。オーサリング可能なレベルは `0–3` で、Max は `1` 以上。Enabled の場合に表示。Play Mode 中はロックされます。 |
| **Transition Metric** | メッシュ LOD の選択に **Screen Size** のパーセントを使うか、**Distance** のメートルを使うかを選びます。 | Screen Size。Enabled かつ Max が Min より大きい場合に表示。 |
| **Reference FOV** | プロジェクトの FOV Tracking が有効な場合に、オーサリングした Distance の境界に対して使う基準の垂直視野角です。 | `1–179` 度。追加/リセット時に透視投影の Camera.main から設定され、ない場合は `50`。Distance または指標が混在した選択の場合に表示。 |
| **Shadow Cast Max Level** | 選択したレベルの終わりの境界以降でシャドウの投影を止めます。カメラからの可視性は継続します。 | **Every level casts** (`-1`)。有効な複数レベルの範囲がある場合に表示。 |

単一レベルの範囲には遷移がありません。不完全なラダーは、不足している境界が供給されるまで、
オーサリング済みの最も詳細なレベルにとどまります。レベル範囲を広げるか、
**Author the missing N boundaries** を使うと、不足しているエントリが供給されます。
範囲を狭めても既存の境界値は保持されます。

### Screen Size のラダー

**Ratios** バーは、左端の画面全体のカバー率から右に向かってゼロへと減少します。レベルの
境界や Culled の端をドラッグして編集します。バーの下にある数値スライダーでも同じ
オーサリングができます。

| 設定 | 用途 | 単位とオーサリングの初期値 |
| --- | --- | --- |
| **LOD n Transition (% Screen Size)** | LOD n から次のレベルに移るときの、インスタンスのバウンディングスフィアの画面高さに対するカバー率です。境界は降順で、隣接する境界を越えることはできません。 | パーセント。`0.01–100` で、さらに隣接する境界によって制約されます。新たに供給されるエントリは `50%` から始まり、`25%`、`12.5%` と半分になっていきます。 |
| **Culled (% Screen Size)** | このカバー率を下回るとインスタンスの描画が止まります。Culled の領域はバーの右端を占めます。 | `0–100%` で、最後の遷移より小さい値に制約されます。既定値の `0` で比率によるカリングを無効にします。 |

API の比率の値は割合です。`0.5` は Inspector の `50%` に対応します。
透視投影の FOV は、プロジェクトの FOV Tracking のトグルとは関係なく自動的に反映されます。
正投影や使用できる FOV がない場合の評価では、保存されている Reference FOV にフォール
バックします。正投影のサイズをモデル化するものではありません。この指標では Reference FOV は
非表示です。確認・編集するには Distance に切り替え、その後で戻してください。

オーサリングした Draw Range の Min/Max は有効なままですが、比率の軸上には描画されません。
いずれかがオーサリングされている場合は説明のメッセージが表示されます。Fade Width と
Hysteresis もメートルのままで、比率の帯としては描画されません。

### Distance のラダー

**Distances** バーは、左端のカメラから右の最も粗いレベルに向かって増加します。境界を
ドラッグするか、その数値フィールドを編集します。

| 設定 | 用途 | 単位とオーサリングの初期値 |
| --- | --- | --- |
| **LOD n Transition (m)** | LOD n から移るときの、カメラから各インスタンスの AABB 表面までの距離です。境界は昇順で、隣接する境界とオーサリングした遠方カリングの制限によって制約されます。 | メートル。新たに供給されるエントリは `100 m` から始まり、`200 m`、`400 m` と倍になっていきます。 |
| **Culled** バーの領域 | オーサリングした Draw Range の制限を距離の軸上に可視化します。 | 上の Draw Range の行で編集します。 |

Distance と Screen Size のラダーは別々に保存されます。指標を切り替えると、もう一方の
ラダーを変換するのではなく、その指標でオーサリングした値が復元されます。Distance による
選択では、正投影や使用できる FOV がないビューに FOV 補正を適用しません。前述の保存された
Reference FOV へのフォールバックは Screen Size による選択のものです。プロジェクトの
**LOD > Distance Scale**、**LOD Bias**、**Min Level**、および任意の **FOV Tracking** は、
オーサリングしたラダーを書き換えずに評価に影響します。
[Graphics Settings](GraphicsSettings.ja.md) を参照してください。

どちらのバーでも、グレー表示の LOD セグメントは、プロジェクトの Min Level によってより粗い
メッシュに引き上げられたレベルを示します。混在したラダーではプレースホルダーが表示されます。
個々の境界を編集するには、コンポーネントを 1 つ選択してください。Distance のフェードの帯の
重なりについて警告が出ることがありますが、Fade Width が自動で縮められることはありません。

### シャドウのカットオフと不足しているレベル

**Shadow Cast Max Level** には、最も粗いレベル以外の各レベルが選択肢として表示されます。
最も粗いレベルの後でシャドウの投影を終えても何も変わらないためです。最も粗いレベル以上の値は
**Every level casts** と表示され、ウィンドウの最小値より小さい値はその最小値まで引き上げられます。
カットオフはオーナーのフェード/遷移の挙動に従います。有効な複数レベルのラダーがない場合、
このカットオフのためのレベル境界はありません。

ソースメッシュに要求されたレベルがない場合は、そのメッシュが持つ最も粗いレベルが使われます。
LOD が有効な単一選択では、影響を受けるメッシュとインスタンスの数が情報メッセージで報告されます。
読み取り専用の一覧を見るには **Meshes without the level** を展開します。必要なメッシュレベルは、
モデルインポーターか[オペレーションウィンドウ](OperationsWindow.ja.md)で生成してください。

## SpeedTree コンテンツ

Inspector に SpeedTree の風のコントロールはなく、SIS は風をシミュレーションしません。
マテリアルが SpeedTree の風キーワードを有効にしているベイク済みの描画グループに対し、
[オペレーションウィンドウ](OperationsWindow.ja.md)の明示的なベイク操作は風を取り除いた
クローンマテリアルを生成し、SIS はそのクローンを描画します。これにより木は風の頂点処理
コストなしで静止状態で描画されます。クローンが生成されていないグループは元のマテリアルを
使い続け、静止状態で描画されますが、風の頂点処理コストは引き続きかかります。再ベイクして
クローンを生成してください。

## Debug (Development)

これらのコントロールは、挙動の確認や描画構成の比較に使います。最初のグループはこの
コンポーネントに属し、**Global (all SIS)** はすべての SIS に影響します。

| コンポーネントの設定または表示 | 用途 | 既定値と条件 |
| --- | --- | --- |
| **Forced LOD** | メッシュ LOD を、オーサリングしたウィンドウ内のレベルに固定します。Auto で自動選択に戻ります。Draw Range のフェードは有効なままです。 | **Auto** (`-1`)。 |
| **Effective LOD Fade** | LOD の強制とグローバルなフェードのゲートを反映した後の、実効的なメッシュ遷移モードです (読み取り専用)。 | 導出値。メッシュ LOD を強制すると None になります。 |
| **LOD Offset** | 選択されるレベルをずらします。正の値で粗く、負の値で詳細になります。結果はコンポーネントのレベル範囲内に収まります。 | `0`。スライダーの幅はウィンドウの深さに従い、最小幅は `-1–1` です。 |
| **Visible** | オフにすると、描画リソースを保持したまま、このコンポーネントのカメラとシャドウへの出力を抑制します。 | オン。 |
| **Cast Shadows** | このコンポーネントのシャドウ投影のマスターマスクです。オンの場合も、ソースレンダラーの ShadowCastingMode は尊重されます。 | オン。 |
| **Instances** | 初期化済みのインスタンス数です (読み取り専用)。 | Play Mode、単一選択時。 |
| **Draw Groups** | メッシュ、サブメッシュ、マテリアル、レンダラー属性でグループ化された、初期化済みのインスタンス描画グループの数です (読み取り専用)。 | Play Mode、単一選択時。 |
| **Unique Meshes** | 登録済みのメッシュ数です (読み取り専用)。 | Play Mode、単一選択時。 |
| **Unique Materials** | 登録済みのマテリアル数です (読み取り専用)。 | Play Mode、単一選択時。 |

ランタイムのカウントは初期化済みのコンテンツを表すもので、フレームごとの可視インスタンス数や
ドローコール数のカウンターではありません。Play Mode 外では、カウントの代わりにメッセージが
表示されます。Play 中の複数選択では、スキャッターを 1 つ選択するよう求められます。

| Global (all SIS) の設定 | 用途 | 既定値と条件 |
| --- | --- | --- |
| **Cross Fade Enabled** | すべての SIS にわたるメッシュ LOD と Draw Range のフェードの、開発用のマスクです。 | 初期値はオン。実際の挙動にはプロジェクトのフェード設定も必要です。Play Mode のみ。URP の LOD Cross Fade がオフの場合は無効。 |
| **Forced LOD (Global)** | すべての SIS をあるメッシュ LOD に強制し、各コンポーネントがサポートするウィンドウ内に制限します。Auto の場合はコンポーネントの選択に任せます。 | **Auto**。Play Mode のみ。 |

グローバルなマスクは一時的なもので、コンポーネントとともに保存されることはありません。
スクリプティングドメインがリセットされると既定値に戻ります。Inspector は、スクリプトの
再コンパイル時や Play Mode の終了時にリセットされることを警告します。ドメインのリロードを
無効にする Play Mode オプションを使う場合も、保存される設定として頼らないでください。
保存されるプロジェクト設定には [Graphics Settings](GraphicsSettings.ja.md) を使います。
強制する LOD を変更しても、オーサリングした Fade Mode は保持されます。自動のメッシュ遷移に
戻すには Auto に戻してください。
